# Contributing to trdr

trdr is released under the AGPLv3, but it is not open to outside code yet.

## External code contributions are closed for now

**We do not accept pull requests from outside the project during this initial phase.**
A PR opened against this repository will be closed with a pointer to this document. This
is not a judgment on the change or its author. The project has not yet decided its
contributor licensing terms, and merging outside code before that decision would leave
the license history of the codebase unclear.

Still undecided, and deliberately so:

- DCO sign-off or a CLA, and which one
- contributor copyright and any future relicensing terms
- fork PR review, merge and release policy

None of these can be inferred from the AGPLv3 release. The AGPL grants you rights to
*use, modify and redistribute* trdr. It grants the project no right to relicense your
contribution. We will decide and publish these terms before opening contributions.

## What is welcome right now

**Issues.** They are the intake path and the work-tracking path for this project.

| You have | Open |
|---|---|
| A bug, a crash, a wrong number | A bug issue with what you did, what you expected, what happened |
| A proposal or a feature request | A proposal issue describing the problem before the solution |
| A question about scope or a contract | A question issue, after checking `docs/` |
| A security vulnerability | Nothing public — follow [`SECURITY.md`](SECURITY.md) |

Please include your macOS version and hardware, and never paste API keys, account
numbers, account balances or terminal output containing them into an issue.

Every project change is tracked against an accepted issue, so an issue is a real
contribution here even when no patch is attached to it.

## Forking

The AGPLv3 lets you fork, modify and redistribute trdr, including commercially, under
the same license and with source available to your users. Two things do not travel with
the code grant: the project's name and logo, and the official Apple signing and update
identity. Read [`TRADEMARKS.md`](TRADEMARKS.md) before you publish a build.

## If you already wrote a patch

Keep it in your fork and open an issue describing the problem it solves. When the
contributor licensing terms are published, that issue is where we will come back to it.
