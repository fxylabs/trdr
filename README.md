# trdr

Agent-native honest trading terminal. Pre-release — not yet public.

- Strategy-as-code: natural language → declarative spec → deterministic replay
- Pre-registration ledger: rules are hashed and timestamped before data is seen
- Out-of-sample discipline: a strategy is noise until proven otherwise
- Cockpit UI: web UI in an Electron shell — dockview panes, embedded terminal
  (bring your own agent), real-time charts from the user's own broker keys

Status: scaffold. See the MVP scope contract in the superself work graph (w-v3aq0).
