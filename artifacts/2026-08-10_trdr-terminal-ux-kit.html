03

Terminal은 명령하고, 중앙 화면은 보여줍니다.

Agent가 trdr CLI의 구조화된 명령을 실행하면 앱이 화면을 열고 결과를 다시 stdout으로 반환합니다.

화면 전환은 승인 없이 실행할 수 있습니다. 등록·삭제·모의검증 시작처럼 상태를 바꾸는 명령은 CLI가 직접 실행하지 않고 approval request를 발행합니다.

Interaction invariants

UX contract
01
Terminal session never moves

중앙 화면이 바뀌어도 PTY와 scrollback은 유지됩니다.

02
Navigation is explicit

자연어를 추측하지 않고 trdr ui 명령만 화면을 제어합니다.

03
App owns durable change

승인과 결과 기록은 terminal TUI가 아니라 앱이 책임집니다.

04
Every command returns

성공·거절·오류는 동일 세션의 stdout으로 돌아갑니다.

04

승인은 terminal card가 아니라 앱 dialog입니다.

명령, 영향, 변경 범위를 한 번에 보여주고 사용자의 결정은 원래 CLI 세션으로 반환합니다.

Dialog는 “Agent가 하려는 말”이 아니라 실제 실행될 trdr 명령을 설명합니다. Phase 1/2에서는 외부 주문 없음 여부를 항상 명시합니다.
