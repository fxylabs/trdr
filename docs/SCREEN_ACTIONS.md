# trdr v0 화면·액션 명세

> 작성 2026-08-06. 근거: docs/PRD.md · docs/USER_STORIES.md ·
> docs/USER_JOURNEY.md, 결정 01kzbjzf(전부 pane이다) · 제안 01kzbjzs(배치 규칙).
>
> 저니 맵은 "사용자가 지나는 순서"를 말한다. 이 문서는 그 순서를 화면 단위로
> 형식화한다 — **어떤 화면에 어떤 액션 지점이 있고, 그 액션이 무엇을
> 작동시키거나 어느 화면으로 데려가는가.** 목업의 `data-goto`·`data-toast`와
> 구현의 이벤트 핸들러가 여기서 나온다.
>
> 이 문서가 정하지 않는 것: 시각 디자인, 데이터 스키마, CLI 프로토콜
> (에이전트용 상태 인터페이스는 w-b2v8x).

## 1. 표기법

### 1.1 개체 ID

| 접두사 | 뜻 | 예 |
|---|---|---|
| `VW-` | 전체 화면 — 앱 셸을 덮는다 | `VW-ONBOARD` |
| `SH-` | 앱 셸의 레이아웃 프리셋 | `SH-TODAY` |
| `PN-` | pane | `PN-CHART` |
| `A-` | 액션 지점 | `A-LIST-03` |

pane은 인자를 가질 수 있다: `PN-CHART(005930)`.

### 1.2 결과 종류

액션의 결과는 아래 8종 중 하나다. **그 외의 결과를 가진 액션은 만들지
않는다.**

| 기호 | 뜻 | 사용자가 보는 것 |
|---|---|---|
| `PLACE` | pane을 새로 놓는다 | 화면에 pane이 늘어난다 |
| `SWAP` | 이미 있는 pane의 내용을 바꾼다 | pane 수는 그대로, 내용이 바뀐다 |
| `FOCUS` | 이미 있는 pane으로 포커스만 옮긴다 | 아무것도 늘지 않는다 |
| `OPEN` | 전체 화면으로 전환한다 | 앱 셸이 가려진다 |
| `RUN` | 비동기 작업을 시작한다 | 진행 표시. 결과는 나중에 다른 곳에 도착 |
| `WRITE` | 영속 상태를 바꾼다 | 다음에 앱을 열어도 남아 있다 |
| `TELL` | 설명만 한다 | 토스트·툴팁. 상태가 안 바뀐다 |
| `REFUSE` | 의도적으로 막는다 | 왜 안 되는지 말한다 |

**죽은 액션 금지**: 누를 수 있어 보이는 모든 요소는 위 8종 중 하나를
가진다. 아무것도 안 하는 요소는 누를 수 있어 보이면 안 된다.

### 1.3 행위자

| 표기 | 뜻 |
|---|---|
| 사람 | GUI 클릭·입력. 사람만 |
| 명령 | 앱 안 명령줄 |
| 에이전트 | trdr CLI 경유 |
| 앱 | 사용자 조작 없이 앱이 |

**동작 일치 원칙**: 같은 액션을 사람·명령·에이전트가 부르면 같은 함수다.
행위자 칸이 다른 것은 **누가 그 액션을 부를 수 있는가**만 뜻한다.

## 3. 명령 문법

### 3.1 형태

```
입력   ::= 티커 [ 명령 [ 인자 ] ]
         | 명령 [ 인자 ]
티커   ::= 6자리 종목코드 | 종목명
명령   ::= 차트 | 수급 | 공시 | 스펙 | 백테스트 | 등록 | 전략
         | 관찰 | 기록 | 수집 | 설정 | 목록 | 터미널
```

- 한국어가 1차. 영문 별칭(`ch` `flow` `disc` `spec` `bt` `reg` `obs`
  `hist` `data` `cfg` `list` `term`)과 한영 오타 보정이 같은 자리를 받는다.
- **티커만** = 차트. PRD §6.1 유지.
- **명령만** = 현재 포커스된 pane의 종목에 적용. 종목이 없으면 종목 없는
  pane(`기록` `설정` `수집`)만 열린다.
- PRD의 명령 9개에 `목록` `공시` `터미널` `전략`을 더해 13개다 — pane
  카탈로그가 전부 명령으로 열려야 하기 때문이다(카탈로그 메뉴를 만들지
  않기로 한 결정 01kzbjzf의 귀결).

### 3.2 입력 → 결과 매핑

| 입력 | 결과 | 대상 |
|---|---|---|
| `005930` | `SWAP` 또는 `PLACE` | `PN-CHART(005930)` |
| `005930 수급` | `SWAP` 또는 `PLACE` | `PN-FLOW(005930)` |
| `005930 백테스트` | `RUN` → `PLACE` | `PN-BT` |
| `목록` | `PLACE` | `PN-LIST` |
| `등록` | `PLACE` | `PN-REG(현재 스펙)` |
| `기록` | `PLACE` 또는 `FOCUS` | `PN-REGISTRY` |
| `수집` | `RUN` + `PLACE` | `PN-DATA` |
| `설정` | `PLACE` 또는 `FOCUS` | `PN-SET` |

`SWAP` / `PLACE` 갈림 (제안 01kzbjzs):

| 조건 | 결과 |
|---|---|
| 같은 종류 pane이 있고 고정되지 않음 | `SWAP` — 내용만 바뀐다 |
| 같은 종류 pane이 있고 고정됨 | `PLACE` — 포커스된 pane 옆에 |
| 같은 종류 pane이 없음 | `PLACE` |
| 같은 종류 pane이 같은 인자로 이미 있음 | `FOCUS` — 중복을 만들지 않는다 |

### 3.3 입력 실패

| 실패 | 결과 | 사용자가 보는 것 |
|---|---|---|
| 없는 티커 | `TELL` | 가장 가까운 후보를 제시 |
| 없는 명령 | `TELL` | 오타 보정 후보 또는 명령 목록 |
| 상폐 티커 | `PLACE` | pane은 열리고 "시세 없음 · 이력만" 표기 **(미결 2)** |
| 종목 필요한 명령을 종목 없이 | `TELL` | 티커를 먼저 지정하라고 |
| 데이터 미커버 구간 | `TELL` | 어디까지 있는지 + `수집`으로 안내 |

## 7.1 결정 01kzbq7y가 닫은 것

성적을 저장된 데이터로 나중에 계산하는 구조가 되면서 3가지가 정리됐다.

| 이전 미결 | 이제 |
|---|---|
| 관찰을 중단할 수 있는가 | 없다. `A-OBS-05`는 화면에서 접기일 뿐이다 |
| 관찰이 앱 실행 중에만 도는가 (미결 10) | 도는 것이 없다. 물어볼 때 계산한다 |
| 관측 결손이 있는 결과의 취급 (미결 9) | 백필로 복구한다. 복구 못 하는 구간만 표기 대상 |

**남는 경계 하나**: 성적을 아무 때나 볼 수 있으면 좋아 보일 때 결과라고
부르고 싶어진다. 그래서 종료일 전 숫자에는 "참고용"이 붙고 결과 스탬프가
나오지 않는다(`A-STR-02`·`A-STR-06`). 사전등록이 실제로 고정하는 것은
**해시와 종료일** 둘이다.

## 8. 목업이 이 문서를 쓰는 방법

| 목업 요소 | 이 문서의 대응 |
|---|---|
| `data-goto="<화면id>"` | 결과가 `PLACE`·`SWAP`·`FOCUS`·`OPEN`인 액션 |
| `data-toast="<설명>"` | 결과가 `TELL`·`RUN`·`WRITE`인 액션 |
| 눌러도 안 되는 것 | 결과가 `REFUSE`인 액션 — 왜 안 되는지 말한다 |
| 아무 속성도 없는 요소 | 누를 수 있어 보이면 안 된다 |

프레임을 그릴 때 그 화면의 액션 표를 옆에 두고, **표의 모든 행이 프레임
안에 존재하는지** 확인한다. 표에 없는 액션 지점을 그리면 표를 먼저 고친다.
