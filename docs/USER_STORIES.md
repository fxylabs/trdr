# trdr v0 유저스토리 (요구사항 명세)

> 작성 2026-08-06. PRD(docs/PRD.md)에서 도출 — 목업이 필요로 하는 층:
> 누가, 언제, 왜 그 화면에 와서, 무엇을 하고 나가는가. 실패 경로 포함.
> 배우는 3종: **사용자**(user zero), **에이전트**(BYO, CLI·파일로 조작),
> **앱**(자동 동작). 목업 v2 열의 ●는 v2에서 새로 그릴 화면, ○는 v1 갱신.
